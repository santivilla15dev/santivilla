# Santi Villa — portafolio + demos
# https://santivilla.com

## Setup local
1. `npm install`
2. Copia `.env.example` → `.env.local` y pon tu WhatsApp + Cal.com
3. `npm run dev` → http://localhost:3000

## Rutas
- `/` — Home / marca personal
- `/trabajos` — Demos + antes/después Lugner + precios
- `/servicios` — Paquetes
- `/contacto` — WhatsApp, email, Cal embed
- `/demos/lugner` — Redesign Konzept (DE, no oficial)
- `/demos/restaurant` — Plantilla Gasthaus

npx vercel
# luego añade el dominio santivilla.com en el dashboard
